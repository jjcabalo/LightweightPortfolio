# JOHN OF ALL TRADES

A minimal, editorial portfolio for **John Jervys** — Software Engineer, UI/UX Designer, and Multimedia Specialist. Built with a monochrome-first aesthetic, adaptive light/dark polarity, animated acid-dissolve transitions, film grain texture, and a reactive custom cursor.

## Stack & Structure

- **Framework**: Next.js (App Router), TypeScript, Tailwind CSS
- **Motion & 3D**: Framer Motion, Lenis smooth scroll, Three.js particle field
- **Pages**: `/` (Work, AI Workflow, Experience, Credentials, Awards), `/about` (JOHN.ABOUT), `/gallery` (JOHN.GALLERY)

```bash
npm install
npm run dev
```
